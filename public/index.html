01 / Carrier and motional sidebands · §7.6.2

Two internal states, |0⟩ and |1⟩, encode a spin qubit. The ions share a quantized center-of-mass mode with phonon number n. All dynamics are in a resonant interaction frame, with the rotating-wave and first-order Lamb–Dicke approximations.

Carrier: |0,n⟩ ↔ |1,n⟩   at ω₀
Red: |0,n⟩ ↔ |1,n−1⟩   at ω₀ − ωz
Blue: |0,n⟩ ↔ |1,n+1⟩   at ω₀ + ωz

Write Hc/ℏ = Ω(eⁱφ |1⟩⟨0| + h.c.)/2 and Hr/ℏ = iηΩ(eⁱφ |1⟩⟨0|a − h.c.)/2; replace a by a† for blue. Carrier θ = Ωt; sideband θ = ηΩt, with effective pair angles θ√n (red) and θ√(n+1) (blue). Ω includes any collective-mode normalization.

The phase slider follows these Hamiltonians. Changing η at fixed sideband θ changes the required duration Ωt, rather than the state. This mode retains n = 0…3; its offered inputs reach at most n = 3, so no populated transition is cut off. A red pulse leaves |0,0⟩ dark. Coherent sideband driving alone is not cooling; cooling also needs dissipation.

02 / A phase from an auxiliary state · §7.6.3

The selected pair |1,1⟩ ↔ |a,0⟩ is driven coherently. The auxiliary transition uses a Hermitian two-level Hamiltonian, Haux/ℏ = Ωaux(|a,0⟩⟨1,1| + h.c.)/2. Its coupling phase is a convention; its 2π phase flip is invariant.

|1,1⟩ → cos(A/2)|1,1⟩ − i sin(A/2)|a,0⟩
A = 2π ⇒ |1,1⟩ → −|1,1⟩
CZ = diag(1, 1, 1, −1)

A π pulse moves the coupled component entirely to the auxiliary level; 2π returns it with a minus sign; 4π returns with no sign change. An incomplete return leaves population outside the computational space. The displayed probabilities retain this population without postselection.

03 / Two ions, one phonon bus · Eq. (7.126)

Ion j is the control and ion k is the target. The bus starts in |0⟩. Following the textbook's construction, we map the target state to the bus, apply the phase operation on the control ion, and undo the map.

M: |1,0⟩ → |0,1⟩, |0,1⟩ → −|1,0⟩
CNOTjk = Hk Mₖ⁻¹ CZj,bus Mₖ Hk
Input |+0⟩ → (|00⟩ + |11⟩)/√2

The red-sideband map uses phase φ = π; its inverse reverses the pulse angle. Using the same map twice would introduce a relative sign. The full 12 amplitudes include the control auxiliary state and bus n = 0,1. This subspace is closed for the offered sequence and initial bus state, including imperfect auxiliary pulse areas.

Sequence progress is a normalized coordinate through gate blocks, not laboratory time. H blocks follow the unitary interpolation Hᶠ (0 ≤ f ≤ 1); H itself is an ideal composite single-qubit operation, obtainable from carrier rotations. Different blocks need different physical durations.

04 / Spin–phonon experiment & readouts · §7.6.4

Here the phonon is the control and the internal spin is the target. The phase-corrected construction H → CZ → H gives exact CNOT. The textbook's Ramsey sequence Ry(π/2) → CZ → Ry(−π/2) gives controlled(−X), equal to CNOT followed by Z on the phonon. Basis probabilities agree, but superposition phases differ.

F = |⟨ψideal | ψ⟩|²
P(q) = Σn |⟨q,n | ψ⟩|²
⟨n⟩ = Σn n P(n)

Fidelity compares the full current state to the ideal final output for the selected input and construction, including a reset bus in ion–ion mode. It is not an average gate fidelity. A zero amplitude has no defined phase; its phase dial is hidden.

Reference: Nielsen & Chuang, Quantum Computation and Quantum Information, §7.6, pp. 309–324. The historical demonstration used one ⁹Be⁺ ion, with internal and motional qubits; it was not a two-ion CNOT. See also Monroe et al. (1995).

Model scope: This simulator illustrates the ideal, resonant gate mechanisms of §7.6. It assumes a prepared motional state and selective laser addressing. Heating, dephasing, spontaneous emission, off-resonant transitions, other motional modes, and trap micromotion are not included. The textbook highlights motional-state preparation and phonon coherence as key limitations.
