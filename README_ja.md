# イオントラップ量子コンピュータ・シミュレータ

ニールセン＆チャン『Quantum Computation and Quantum Information』7.6節（pp. 309–324）の理想モデルを、ブラウザで操作できるシミュレータです。既存の調和振動子・光子・光共振器QEDシミュレータと同じ濃紺のパネル、青・緑・紫の配色を使っています。画面の言語も既存版に合わせて英語です。

## 3つの実験

- **Ion–ion quantum gate**：2個のイオンと共有フォノンによるCNOT／CZ。教科書の式(7.126)に従い、ターゲットを振動へ写し、制御イオンの補助準位を使って位相反転を行い、逆写像で戻します。初期値 `|+0⟩` はCNOT後にベル状態になります。
- **Carrier & sidebands**：キャリア、赤サイドバンド、青サイドバンドの駆動。パルス面積・レーザー位相・Lamb–Dickeパラメータを変更し、暗状態やフォノン交換、√nに依存する振動速度を確認できます。
- **Spin–phonon gate**：1個のイオンの内部状態と運動状態を使うゲート。フォノンが制御、スピンがターゲットです。正確なCNOTと、教科書のRamseyパルス列に残る相対位相の違いを比較できます。

`Input`、`Mid-pulse`、`Output`や各段階のボタンで観測点を選べます。再生ボタンで連続的に追い、`Auxiliary pulse area A`を変えると不完全なパルスによる補助準位への漏れも見られます。振幅・相対位相・測定確率・フォノン分布・理想出力との忠実度を表示します。タブ切り替え時は設定を保持し、リセットは現在の実験だけを初期化します。

## 計算の読み方

イオン間ゲートの論理入力は `|制御,ターゲット⟩`、全振幅は `|制御 ターゲット,フォノン数⟩` です。単一イオンの全振幅は `|スピン,フォノン数⟩`、Spin–phononモードの論理入力・測定バーは `|フォノン,スピン⟩` の順です。`a`は計算用の0/1とは別の補助準位を表します。

2πパルスは元の準位へ戻った成分に−1の位相を付けます。πではその成分が補助準位に残り、4πでは位相反転が消えます。補助準位の確率を捨てたり、計算部分だけを再規格化したりしていません。

キャリアの面積は `θ=Ωt`、サイドバンドでは `θ=ηΩt` です。サイドバンドのηを固定面積のまま変えると、状態ではなく必要時間が変わります。ゲート列の進行度は各ブロックを等間隔に並べた座標で、実験時間ではありません。Hはキャリア回転で構成できる理想的な単一量子ビット演算とし、途中の可視化には `H^f` を用いています。

忠実度は現在の**全状態**と理想的な**最終出力**の重なりです。イオン間ゲートではフォノンが基底状態へ戻ることも含めて評価しています。平均ゲート忠実度ではありません。

共鳴・回転波近似・一次のLamb–Dicke近似、理想的な初期化と個別アドレスを仮定しています。加熱、位相緩和、自然放出、他の振動モード、マイクロモーションは含めていません。7.6.4の歴史的な単一イオン実験と、2個のイオンを使う理想的な構成は別の実験として扱っています。
